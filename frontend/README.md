# Nanny Services Frontend

Next.js client application for the Nanny Services platform.

## Status

The frontend is currently in the initial setup phase. The REST API is available
in the sibling `backend` directory.

## Tech Stack

- Next.js with App Router
- TypeScript
- Tailwind CSS
- Zustand

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

See the root [README](../README.md) for the full project overview and
[API documentation](../docs/API.md) for backend routes.
